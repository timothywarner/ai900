## Practice Question Strategy

### Phase 1: Diagnostic (Week 1)

**Goal**: Establish baseline and identify weak areas

1. **Take Microsoft Learn Practice Assessment** (30-40 min)
   - Don't study first - establish true baseline
   - Note: Domain scores (which % are weak?)

2. **Try MeasureUp Assessment** or **Whizlabs Diagnostic** (if purchased)
   - Identifies specific topic gaps
   - Creates personalized study plan

3. **Record Results**:

   ```text
   AI Workloads: 60%  <- WEAK!
   Machine Learning: 75%
   Computer Vision: 80%
   NLP: 70%
   Generative AI: 65%  <- WEAK!
   ```

### Phase 2: Learning (Weeks 2-3)

**Goal**: Study weak areas with targeted practice

**Daily Routine:**

- Morning: Study one domain (use course materials)
- Evening: 10-15 practice questions on that domain
- Use ExamTopics/ITExams for free daily practice

**Best Practices:**

- Read question carefully (keywords: "best", "least", "should")
- Eliminate obviously wrong answers first
- Read explanation EVEN IF correct (learn why)
- Create flashcards for tricky concepts
- Revisit weak areas every 3 days

### Phase 3: Practice Exams (Week 4)

**Goal**: Build exam stamina and confidence

**Schedule:**

1. **Monday**: Full practice exam #1 (60 min)
   - Review all answers (90 min)
   - Note weak topics

2. **Wednesday**: Targeted study on weak topics (2 hours)

3. **Friday**: Full practice exam #2 (60 min)
   - Compare scores to Monday
   - Should see improvement!

4. **Saturday**: Review mistakes + create summary notes

5. **Sunday**: Light review, rest, prepare for exam week

**Target Scores:**

- 1st practice exam: 70%+ (passing)
- 2nd practice exam: 80%+ (comfortable)
- 3rd practice exam: 85%+ (ready!)

### Phase 4: Final Week

**Goal**: Reinforce weak areas, stay sharp

**Daily:**

- 20-30 practice questions (mix of all domains)
- Review incorrect answers from previous exams
- Focus on highest-weight domain: **Generative AI (20-25%)**

**Day Before Exam:**

- NO new topics
- Review summary notes
- Light practice (10-15 questions)
- Get good sleep!

## Question Types & Strategies

### Multiple Choice (Most Common)

**Example:**

> Which Azure service should you use to identify the language of a text document?
> A) Azure Translator
> B) Azure AI Language
> C) Azure OpenAI Service
> D) Azure Speech

**Strategy:**

- Read question stem carefully
- Identify keywords ("identify language" = detection, not translation)
- Answer: B (Language service has detection, Translator assumes known language)

### Multiple Response (Select ALL that apply)

**Example:**

> Which of the following are responsible AI principles? (Select 3)
> Fairness
> Profitability
> Privacy and Security
> Efficiency
> Transparency

**Strategy:**

- Know there are exactly 6 principles: FAIR-PT
- Fairness, Accountability, Inclusiveness, Reliability & Safety, Privacy & Security, Transparency
- Answers: Fairness, Privacy & Security, Transparency

### Scenario-Based (Increasing in Frequency)

**Example:**

> A company wants to analyze customer feedback emails to determine if they are positive, negative, or neutral. They need to process thousands of emails daily and prefer a managed solution. Which Azure service should they use?

**Strategy:**

1. Identify requirements:
   - Task: Sentiment analysis
   - Volume: High (thousands)
   - Preference: Managed (not custom)
2. Match to service: Azure AI Language (sentiment analysis)
3. Why not others:
   - Azure OpenAI: Overkill for simple sentiment
   - Custom model: Not preferred (wants managed)
   - Azure ML: Would require training

### Drag and Drop / Ordering

**Example:**

> Arrange the machine learning workflow in the correct order:
> Deploy model, Train model, Collect data, Evaluate model

**Strategy:**

- Know the standard ML lifecycle
- Correct order: Collect data, Train model, Evaluate model, Deploy model

## Sample Questions by Domain

### Domain 1: AI Workloads (15-20%)

**Q1:** A retail company wants to ensure its AI-powered hiring tool treats all candidates fairly regardless of background. Which responsible AI principle is most relevant?

- A) Reliability and Safety
- B) Fairness (CORRECT)
- C) Privacy and Security
- D) Transparency

**Explanation:** Fairness addresses bias and equitable treatment. This scenario specifically asks about fair treatment across different groups, making Fairness the primary principle. While Transparency could help identify bias, the question focuses on equal treatment.

---

**Q2:** Which of the following are common AI workloads? (Select all that apply)

- Computer vision (CORRECT)
- Natural language processing (CORRECT)
- Data warehousing
- Document processing (CORRECT)
- Network routing

**Explanation:** Computer vision, NLP, and document processing are AI workloads. Data warehousing and network routing are general IT tasks, not AI-specific workloads.

### Domain 2: Machine Learning (15-20%)

**Q3:** A data scientist wants to predict the selling price of houses based on features like square footage, number of bedrooms, and location. Which machine learning technique should they use?

- A) Classification
- B) Clustering
- C) Regression (CORRECT)
- D) Reinforcement Learning

**Explanation:** Regression predicts continuous numeric values (price). Classification predicts categories, Clustering finds groups, and Reinforcement Learning learns through trial and error.

---

**Q4 (NEW!):** What is a key feature of the Transformer architecture used in modern AI models?

- A) It uses convolution layers for image processing
- B) It processes sequences recursively
- C) It uses self-attention mechanisms (CORRECT)
- D) It requires less training data than other approaches

**Explanation:** Transformers use self-attention to focus on relevant parts of input sequences. This is the foundation of models like GPT and BERT. Convolution is for CNNs, recursive processing is for RNNs.

### Domain 3: Computer Vision (15-20%)

**Q5:** You need to extract text from scanned images that contain both printed and handwritten content. Which Azure service should you use?

- A) Azure AI Vision (OCR/Read API) (CORRECT)
- B) Custom Vision
- C) Azure AI Face
- D) Azure AI Document Intelligence

**Explanation:** Azure AI Vision's OCR/Read API handles both printed and handwritten text extraction. Custom Vision is for image classification, Face is for facial analysis, and Document Intelligence is better for structured documents (invoices, receipts) though it also has OCR capabilities.

### Domain 4: NLP (15-20%)

**Q6:** A company wants to build a bot that understands customer intents like "book a flight" or "cancel reservation" and extracts entities like dates and destinations. Which service should they use?

- A) Azure AI Language (sentiment analysis)
- B) Conversational Language Understanding (CLU) (CORRECT)
- C) Custom Question Answering
- D) Azure Translator

**Explanation:** CLU (formerly LUIS) is designed for extracting intents and entities from conversational input. Custom QA is for FAQ-style Q&A, sentiment analysis only determines emotion, and Translator converts languages.

### Domain 5: Generative AI (20-25%)

**Q7 (NEW!):** What is Microsoft Foundry?

- A) A replacement for Azure Machine Learning
- B) A unified platform for developing AI applications with access to 1,600+ models (CORRECT)
- C) A service only for Azure OpenAI models
- D) A tool for creating custom AI models from scratch

**Explanation:** Microsoft Foundry is Microsoft's unified AI development platform that provides access to a vast model catalog including models from Microsoft, OpenAI, Meta, and Hugging Face. It integrates with but doesn't replace Azure ML.

---

**Q8:** Which parameter in prompt engineering controls the randomness/creativity of model outputs?

- A) max_tokens
- B) top_p
- C) temperature (CORRECT)
- D) frequency_penalty

**Explanation:** Temperature (0-1) controls randomness: 0 = deterministic/factual, 1 = creative/random. max_tokens limits output length, top_p controls probability sampling, frequency_penalty reduces repetition.

## Passing Score & Grading

- **Passing Score**: 700/1000 (70%)
- **Total Questions**: 40-60 questions
- **Duration**: 60 minutes (45 minutes exam + 15 minutes tutorial/review)
- **Grading**: Scaled score (not just % correct)

**What This Means:**

- Some questions are weighted more than others
- Performance-based questions (scenarios) worth more
- Aim for 80%+ on practice exams to be comfortable
- Generative AI domain is 20-25% (highest weight!)
