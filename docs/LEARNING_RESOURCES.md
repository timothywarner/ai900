## Exam Tips

### Before the Exam

1. Complete all Microsoft Learn modules for AI-900
2. Take the free official practice assessment
3. Review the skills measured document
4. Get hands-on experience with Azure AI services (free tier available)

### During the Exam

- Read each question carefully - look for key terms
- Eliminate obviously wrong answers first
- Watch for "NOT" or "EXCEPT" in questions
- Time management: ~1.5 minutes per question
- Flag uncertain questions and return to them

### Scoring

- Passing score: 700/1000
- Questions: 40-60 (varies)
- Time: 45 minutes
- Question types: Multiple choice, drag-and-drop, case studies
